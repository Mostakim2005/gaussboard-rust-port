# GaussBoard v7.0.2

## Rust & Tauri v2 Engine Parity, Workflow Studio & Zero-Overlap HUD

GaussBoard v7.0.2 completes the Tauri v2 Rust backend bridge across Windows desktop, Android APK, and PWA runtimes, eliminates floating toolbar collisions, adds a toggleable Material 3 Expressive and Glassmorphism appearance mode, and introduces manual element and protocol visibility controls.

### Highlights
- **Zero-Overlap HUD & Normalized Layers**: Repositioned left-edge triggers (`#pagetab` and `.sidebar-ribbon-latch.dock-left`), enforced mutual exclusion between left drawers and `#audioBar`, updated `visibleArea()` placement clearances, and normalized UI layer stacking tokens.
- **Workflow Studio (Material 3 & Glassmorphism)**: Toggleable visual sheet (`Ctrl+Shift+O`) unifying global UI material switching, Obsidian Vault Markdown modes (`Live preview`, `Source`, `Reading`), clipped vs. freeform page bounds, video bookmark behavior, and audio-ink sync controls.
- **Hide Elements & Subsystem Protocols**: Non-destructive manual element hiding (`Ctrl+H` and context menu) independent of study tape/answer covers, Zen UI chrome hiding (`Alt+Z`), per-bar HUD toggles, and clean protocol switches for Obsidian Vault, LAN Sync, Audio Replay, and Study SRS.
- **Full Rust Backend <-> JS Parity**: All Tauri v2 backend commands registered and bridged (stroke curve fitting preserving stroke timestamps, FTS search and backlinks, SRS scheduling sync, high-res PNG export, `.gaussboard` bundle archive helpers, colorimetry contrast/inversion, power telemetry, and Windows Mica vibrancy) alongside shared JS fallbacks for Web/PWA.
